# Windows AI Memory Control

[English](README.md) · [Инструкция для агента](AGENTS.md) · [Параметры и источники](docs/controls.md)

Небольшой набор PowerShell-скриптов для Copilot+ PC: убрать ненужную фоновую загрузку моделей, сохранить NPU и Windows AI API, а после работы с системными AI-моделями иметь **ручную команду освобождения памяти**.

Проверенный ноутбук: **HP OmniBook X Flip 14-kc0xxx, AMD Ryzen AI 7 445 / Radeon 840M, 24 ГБ RAM, Windows 11 Pro 26H2, сборка 26300.9711**. Это ограниченно проверенная конфигурация, а не универсальный «деблоатер Windows».

## Что меняется

- Отключается семантическая индексация файлов: обычный поиск по словам остаётся, поиск документов/фотографий по смысловому описанию отключается.
- Блокируется наблюдавшаяся автоматическая предзагрузка языковой модели; явные вызовы Windows AI API остаются доступны.
- Отключается AI-агент «Параметров»; обычная навигация и поиск настроек сохраняются.
- Отдельным скриптом можно отключить собственный смысловой поиск примеров в AI Dev Gallery. Обычный поиск примеров и сами API-примеры остаются.

Два системных переключателя внутренние и не документированы как публичные политики. Все детали — в [controls.md](docs/controls.md). Службы Windows AI Fabric и Windows Search, драйверы NPU/GPU и собственные среды исполнения не отключаются. Скрипты не устанавливают LLM и не меняют Recall, Click to Do, System Restore, резервное копирование, Secure Boot или питание. Если Recall/Click to Do не нужны, выключите их обычными переключателями Windows — без административных запретов на последующее включение.

## Запуск

Скачайте/клонируйте репозиторий и просмотрите скрипты. Нужна 64-битная Windows, Windows PowerShell 5.1 или PowerShell 7.

```powershell
# Состояние: только чтение, без прав администратора.
powershell.exe -NoProfile -File .\scripts\WindowsAIMemory.ps1

# Предварительный просмотр без изменений и UAC.
powershell.exe -NoProfile -File .\scripts\WindowsAIMemory.ps1 -Action Apply -AllowExperimental -WhatIf

# Применение: Windows запросит права администратора.
powershell.exe -NoProfile -File .\scripts\WindowsAIMemory.ps1 -Action Apply -AllowExperimental

# Необязательная настройка Gallery; сначала закройте её.
powershell.exe -NoProfile -File .\scripts\Set-GallerySearch.ps1 -Mode Disable

# Ярлыки текущего пользователя на рабочем столе и в «Пуске».
powershell.exe -NoProfile -File .\scripts\Install-Shortcuts.ps1
```

Apply откажется работать на непроверенной сборке/CPU. Параметр `-AllowUntestedSystem` позволяет осознанно продолжить после изучения реализации; совместимость он не гарантирует. Требуются уже существующий ключ семантической индексации и работающие службы Search/AI Fabric с типом запуска Automatic. Владельцы и права системных ключей не меняются. После применения перезагрузитесь сами: скрипт не перезагружает компьютер.

Если Windows блокирует скачанный неподписанный скрипт, сначала изучите его. Можно разблокировать именно скачанные файлы или добавить `-ExecutionPolicy Bypass` только к конкретному запуску PowerShell. Менять общесистемную политику выполнения или отключать UAC не требуется.

## Выгрузить модели без агента

Закройте Gallery и завершите другие запросы к Windows AI API. Нажмите ярлык **Free Windows AI memory** либо выполните:

```powershell
powershell.exe -NoProfile -File .\scripts\WindowsAIMemory.ps1 -Action Unload
```

После установки доступна также команда:

```text
%LOCALAPPDATA%\WindowsAIMemoryControl\Tools\Free-WindowsAI-Memory.cmd
```

Она разово завершает только системные хосты моделей `WorkloadsSessionHost.exe` с проверенным путём пакета Microsoft. Менеджер сеансов, службы, драйверы и собственные процессы FastFlowLM/Lemonade/LM Studio не завершаются. При открытой Gallery команда откажет. Все возможные сторонние клиенты Windows AI определить нельзя: активные API-запросы при такой выгрузке прервутся. Используйте её **после работы**, а не во время генерации.

Если системные хосты есть, Windows попросит подтверждение UAC. Если их нет — повышения прав не будет. Постоянная привилегированная задача, служба, автозагрузка, изменение PATH, обход UAC или фоновый таймер не устанавливаются. Скрипты для ярлыка копируются в LocalAppData: перенос репозитория ярлык не сломает. После обновления инструмента запустите установщик ярлыков ещё раз.

## Откат

```powershell
powershell.exe -NoProfile -File .\scripts\WindowsAIMemory.ps1 -Action Restore
powershell.exe -NoProfile -File .\scripts\Set-GallerySearch.ps1 -Mode Restore
```

Исходные системные значения сохраняются до изменений в `%ProgramData%\WindowsAIMemoryControl\state.json`. Каталог принадлежит администраторам, обычные пользователи не могут менять резервную копию. Повторный Apply её не перезаписывает. Восстанавливается состояние **до первого запуска этого инструмента**, а не придуманные заводские настройки. Если компьютер уже был настроен, именно его текущее состояние станет исходным.

Откат сохраняет изначально отсутствовавшие параметры и существовавшие раньше ключи; при неожиданных внешних изменениях или непустом удаляемом ключе останавливается. При ошибке Apply предпринимается откат, резервная копия сохраняется. Сообщение об ошибке нельзя считать успешной настройкой.

Для Gallery сохраняется только исходное значение её переключателя — полный файл настроек с возможными ключами провайдеров не копируется. Вручную он находится в **Gallery → Settings → App Content Search → Enable app content search**.

## Подтверждённый результат и ограничение

- После перезагрузки и обычной работы системные модели не появились; на исследованном ноутбуке было свободно около 10,3 ГиБ RAM, занято 56%. Объём свободной памяти у другого пользователя будет отличаться.
- Phi Silica и OCR через Gallery продолжали работать.
- При включённом собственном поиске Gallery загружала OCR/поисковые модели уже при открытии. С выключенным поиском повторный запуск главного окна их не загрузил.
- Своя Qwen через Lemonade/FastFlowLM работала на NPU с контекстом 4096 и сама выгрузилась примерно через 302 секунды: процесс модели исчез, память NPU стала нулевой.
- **Полная автоматическая выгрузка Windows AI API не подтвердилась:** после закрытия Gallery около 3,1 ГиБ оставались заняты спустя 380 секунд. После измерения сеансы разово очистили. Поэтому здесь есть ручная команда, а обещания универсальной автовыгрузки нет.

Пятиминутная выгрузка Qwen — настройка её среды исполнения, не функция этого инструмента. Занятая память NPU не равна непрерывным вычислениям. Общая память ускорителя уже входит в системную RAM; прибавлять её к занятой оперативной памяти повторно нельзя. Идентификаторы адаптеров меняются при перезагрузке, поэтому Status выводит исходные счётчики всех адаптеров, не угадывая NPU.

Пределы проверки упакованных скриптов описаны в [validation.md](docs/validation.md). Тесты: `powershell.exe -NoProfile -File .\tests\Run-Tests.ps1` или `pwsh -NoProfile -File .\tests\Run-Tests.ps1`.
